Fault memory ($18 / $14)

Reads stored DTCs by status and decodes them to internal fault codes via analysis/dtc_map.tsv.

Vehicle coding ($23 read / $3D write)

2 bytes + checksum at EEPROM 0x0FA–0x0FC. Writing needs Adjust 10 87 + Unlock 0x7F and takes effect at the next power-on.

Row selects the feature set (0–48). Checksum is computed for you.

Hydraulic valve calibration ($31 0x28 / 0x29, $33 status)

These routines actuate the valves and pump. Run only on a bench with the unit safe to pulse. Refused if a test is already active or the selector is not accepted.

Sensor offset calibration ($31 0x20–0x24)

Car must be stationary; a not-ready routine replies NRC 0x22. Steering zero (0x21) also needs the SZL reporting initialised and the CAN key handshake.

Live data ($21)

0x02 conditioned sensors · 0x05 status byte · 0x06 raw ADC/sensors · 0x07 raw wheel speeds.

Memory read ($23)

Type 3 = EEPROM by address. Useful: 0x0FA coding, 0x160 steering/accel offset record, 0x0F0 steering key.
